# 🏙️ Lost City Project

**Lost City** is a Unity game that immerses players in a mysterious, abandoned city filled with hidden secrets and challenges.  
Explore the environment, interact with objects, and uncover the story

---

## 🛠️ Technologies Used

- **Game Engine:** Unity  
- **Programming Language:** C#  
- **Graphics & Shaders:** Unity materials, ShaderLab, HLSL  

---

## ⚡ Project Features

- **Immersive City Environment:** Navigate through detailed urban ruins.  
- **Interactive Gameplay:** Engage with objects to discover hidden clues.  
- **Atmospheric Design:** Dynamic lighting and environmental effects enhance the mood.  
- **Puzzle & Story Elements:** Solve environmental puzzles to progress the narrative.
